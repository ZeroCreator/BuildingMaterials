## 📊 Формат вывода (JSON)

**Путь сохранения:** `results/suppliers_YYYYMMDD.json`

**Имя файла включает текущую дату** в формате YYYYMMDD (например, `results/suppliers_20260318.json`).

### Структура JSON

```json
[
  {
    "Город": "Хабаровск",
    "Наименование поставщика": "ООО Ромашка",
    "ИНН": "2721234567",
    "Контактное лицо": "Иванов Иван",
    "Телефон": "+7 (4212) 12-34-56",
    "Email": "info@company.ru",
    "Материал": "Бой кирпича",
    "Единица": "м³",
    "Цена": "от 300 руб/м³",
    "Примечание": "Фракция 20-40",
    "Источник": "Yandex",
    "Ссылка": "https://...",
    "Дата": "18.03.2026",
    "Адрес": "680000, Хабаровск, ул. Ленина, 1"
  }
]
```

### Обязательные поля

- Город
- Наименование поставщика
- Материал
- Ссылка

### Дополнительные поля (收集ить если есть)

## 🔍 Процесс сбора

### Этап 1: Поиск организаций

Для каждого материала:
1. Поиск в Яндекс/Google: `"[материал] Хабаровск купить"`
2. Пройти пагинацию (минимум 20-30 результатов)
3. Собрать все найденные организации

### Этап 2: Сбор данных

Для каждой организации:
1. Зайти на сайт
2. Найти каталог/продукцию
3. Искать целевой материал
4. Если найден — собрать данные

### Этап 3: Валидация

1. **Телефон:** Проверить формат (+7 4212 XX-XX-XX для Хабаровска)
2. **Сайт:** Убедиться что открывается
3. **Материал:** Проверить соответствие характеристикам

---

## ⚠️ Важные правила

1. **Не выдумывать данные** — если не найдено, оставить пустым
2. **Сохранять ВСЕ найденное** — не фильтровать
3. **Валидировать что можно** — телефоны, сайты
4. **Дата в имени файла** — обязательно YYYYMMDD
